# Alsiraj Perfumes – Website

A modern, responsive perfume shop website built with **Next.js** and **TypeScript**, focusing on clean UI, performance, and a smooth browsing experience.

## 🌐 Live Demo
https://alsiraj-perfumes.com/

## ✨ Features
- Responsive layout (mobile / tablet / desktop)
- Modern UI sections (Hero, Products, About, Contact)
- Fast performance and SEO-friendly structure
- Clean component-based architecture

## 🧰 Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS

## 🚀 Run Locally
```bash
npm install
npm run dev
